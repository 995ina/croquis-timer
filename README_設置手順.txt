CROQUIS TIMER Ver.1.9 — Mac / iPhone / iPad 共通版

【含まれるファイル】
index.html                 アプリ本体
manifest.webmanifest       ホーム画面用の設定
sw.js                      アプリ本体のオフラインキャッシュ
icons/                     ホーム画面用アイコン

【公開方法：GitHub Pagesの例】
1. GitHubに公開用リポジトリを作成します（公開範囲の設定に注意）。
2. このフォルダの中身をすべてリポジトリのルートに配置します。
3. Settings → Pages → Build and deployment → Deploy from a branch を選択。
4. main / (root) を指定して保存し、発行された https://...github.io/.../ を開きます。
5. iPhone/iPadのSafariでURLを開き、共有 → ホーム画面に追加（「Webアプリとして開く」があればオン）→ 追加。
6. Macでは同じURLをSafari等で開けば使用できます。

【利用方法・重要事項】
・画像ファイルはブラウザ内でのみ読み込み、サーバーへアップロードされません。
・インストール後、一度オンラインでアプリを表示すれば、本体はオフラインでも起動できる構成です。端末・ブラウザによる制限やキャッシュ削除には注意してください。
・選択した画像は保存しません。再起動・再読み込み後は選び直してください。
・iPhoneの「全画面」は通常のFullscreen APIの代わりに画面内の集中表示モードに切り替わります。ホーム画面から開くとブラウザバーを減らせます。
・再生中の画面消灯防止は対応するOS/ブラウザで試みますが、端末設定や省電力状態により必ず成功するとは限りません。
・終了音はiPhoneの消音設定等で鳴らない場合があります。
・GitHub Pages等のHTTPS配信がPWAとサービスワーカーの動作に必要です。file://で開く場合は通常のHTMLアプリとして動作します。
・リポジトリは「公開」にしてもアプリのコードが公開されるだけで、利用者が選んだ画像が公開されるわけではありません。
